# 视频号发布归档

仅负责将已实际发布、且获得明确归档指令的内容写入正式历史知识库，并完成必要的内容资产回流。

## 触发条件

必须同时满足以下两项：

1. 用户已明确说明内容实际发布或已更新完成。
2. 用户明确要求归档、写入知识库或保存到历史内容。

两项缺一不可。用户只说明“已发布”时，只准备唯一可识别的归档预览，不写文件；实际发布信息无法唯一对应标题、正文或日期时，先请求澄清，不得猜测或覆盖已有记录。

## 归档执行

归档前必须完整读取并严格遵循 `财税视频号内容库/00-首页与维护规则/历史内容归档规范.md`。该文件是路径、文件名、Frontmatter、正文结构和完成检查的唯一规则来源；本 Skill 不重复定义归档 Schema。

归档时：

1. 检查目标目录是否存在同名或疑似重复笔记；有冲突时停止并报告。
2. 仅写入实际采用的标题、正文和实际发布日期；不保存备用标题、创作过程或未发布信息。
3. 将对应选题池条目更新为“已发布”，保留其来源与关联历史内容，防止再次推荐。
4. 更新索引、内容地图、重复检查和内容缺口分析；无新增事实时不强行改写统计。

## 回流灵感库

归档后，从已发布内容中提取 1—2 个不重复的后续问题，为每条后续问题新建一篇 `历史延展` 灵感笔记；若存在真实评论、咨询或服务交付反馈，也分别新建独立灵感笔记，并关联本次历史内容。

回流条目先标记为“待分析”，不能直接成为下一次正式选题。流程到此结束，不自动生成下一批选题或文案。
