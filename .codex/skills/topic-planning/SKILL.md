# 视频号选题规划

负责历史扫描、内容覆盖分析、候选来源分析、实质查重、服务承接判断、选题排序，并输出 5 个候选选题。完成后等待用户选择或调整；不得自动生成正式文案、标记发布或归档。

## 执行前必读

每次正式生成选题前，必须读取：

- `财税视频号内容库/00-首页与维护规则/账号基本定位.md`（账号定位唯一事实来源）
- [历史内容库读取规则](references/history-vault-rules.md)

不使用热点 API，不按时段安排选题。

## 候选来源优先级

1. 用户本次指定的业务方向、客户类型或经营问题；
2. 历史内容库识别出的覆盖缺口与近期避重结果；
3. 对应业务选题池中状态为“可推荐”的候选；
4. 灵感库目录中状态为“可入池”的独立灵感笔记，包括真实业务问题与自有化后的竞品观察；
5. 已发布内容的可延展选题；
6. 与账号定位一致的常青经营场景。

历史内容库负责判断“已讲过什么、缺什么、不能重复什么”；灵感库负责积累原始线索；选题池负责提供成熟候选。

## 筛选与核验

对候选依次检查：

1. 定位匹配：优先电商合规；补充业务仍须服务企业经营者。
2. 场景完整：明确目标客户、经营动作、痛点和可承接服务。
3. 实质去重：重点比较近 7 天内容及同主题全部历史内容；仅换标题但客户场景、痛点或服务机会相同，仍视为重复。
4. 事实边界：政策、税率、期限、处罚、平台规则和办理流程必须核验当前官方来源。不能核验时，改为不下确定性结论的经营场景题，或保留为待核验。
5. 合规表达：淘汰依赖恐吓、绝对化承诺、虚构数据或规避监管方法才成立的题目。

## 排序与输出

通过筛选的候选按以下权重排序：客户与财税相关度 30 分、服务承接价值 25 分、场景紧迫性 15 分、内容缺口 15 分、近期差异度 10 分、事实可核验性 5 分。

输出 5 个彼此不复用客户场景、核心痛点或服务机会的方案。每个方案包含：

| 字段 | 要求 |
| --- | --- |
| 选题 | 自有化标题，不复用竞品标题 |
| 目标客户与场景 | 说明谁在什么环节遇到什么问题 |
| 服务关联 | 对应的可承接服务 |
| 入选依据 | 用户需求、内容缺口、真实问题、历史延展或竞品观察 |
| 核验状态 | 常青场景、已官方核验或待核验 |
| 差异说明 | 与近期历史内容的区别 |

用户未明确确认时，不生成定稿，也不将候选视为已发布。
