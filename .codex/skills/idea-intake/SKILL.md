# 灵感录入

仅负责将用户提供的参考内容、竞品内容、图片文字或想法保存为独立灵感。完成一条灵感笔记后立即结束；不得自动分析灵感、生成选题、查询历史库、生成文案、核验政策或写入历史内容库。

## 输入处理

- 用户提供文字：直接写入“原始材料”，不改写、不总结。
- 用户提供图片：只提取图片中可读文字，写入“原始材料”；不保存、嵌入、链接或归档图片本身。
- 图片文字无法完整识别时，如实保留可读部分，并标记“文字识别不完整”；不得补写猜测内容。
- 用户同时给出文字和图片时，保留文字原文，并将图片文字另列为“图片文字提取”。
- 数据表现、原链接或备注仅在用户材料中出现时记录；不要求补充，也不要求记录平台。

## 独立笔记规则

1. 每条灵感建立一篇笔记，保存至 `财税视频号内容库/03-选题规划/灵感库/YYYY/YYYY-MM/`。
2. 文件名使用 `YYYY-MM-DD｜简短名称.md`。简短名称描述材料中可识别的场景，不直接照搬竞品标题；无法判断场景时，使用“待分析灵感”加序号。
3. Frontmatter 固定记录 `title`、`tags`、`status`、`created` 和 `updated`；初始 `status` 一律为“待分析”。不记录来源文件、文件路径或其他文件来源信息。
4. 每篇笔记只保存本次用户提供的文字原文、图片文字提取结果和明确给出的备注；不得补充目标客户、主题、业务线、服务关联、结论或选题建议。
5. `选题灵感收集.md` 仅作为索引和模板说明，不保存多条灵感正文。
