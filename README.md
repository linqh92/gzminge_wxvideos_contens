# 广州敏哥聊财税｜微信视频号

## 1. 仓库内容与用途

本仓库用于管理“广州敏哥聊财税”微信视频号的日常内容生产和获客流程，重点服务电商经营者的财税合规需求。

主要内容包括：

- `财税视频号内容库/`：Obsidian 内容库，保存历史内容、内容地图、选题规划、内容复盘和财税素材。
- `.codex/skills/daily-video-account-planning/`：视频号日更选题、文案生成、风险评估和历史记录工作流。
- `JustOneAPI-token.txt`：本地 Just One API 凭据文件，仅用于垂直行业关键词检索，不保存到版本库。

仓库的主要用途是维护账号历史内容、识别已覆盖和未覆盖的客户场景、发现电商财税经营问题，并据此规划和制作适合视频号发布的内容。

## 2. 当前主要流程

### 选题规划

1. 扫描 `财税视频号内容库/01-历史内容/`，读取历史笔记的标题、日期、业务线、主题、客户场景和内容目标，并阅读最近内容。
2. 分析近 7 天重复主题、长期内容缺口、客户痛点、服务机会和表达角度。
3. 根据账号定位选择电商财税关键词，例如平台流水、平台报送、发票、进项票、个体户、直播电商、平台结算和税务风险。
4. 使用 `JustOneAPI-token.txt` 中的 Token 调用 Just One API，对抖音、小红书、微博和微信进行关键词与时间范围检索。
5. 对返回内容进行相关性筛选，只保留能够对应电商经营、企业财税或老板决策问题的行业热点。
6. 对政策、税率、申报期限、处罚和办理流程等内容补充当前官方来源核验。
7. 输出早、中、晚 3 条必发选题和 2 条备选，并说明客户场景、服务关联、检索关键词、来源链接和核验状态。

如果 Just One API 出现额度不足、预算限制或调用失败，则停止 API 检索，改用历史内容缺口、客户真实问题、公开网页和官方政策信息完成常规选题；必要时生成不依赖即时热点的常青选题。

### 文案生成

用户确认具体时段的选题后，读取原始文案指南，生成该选题的正式文案，包括内容标题、搜索标题、短标题、正文和风险评估。未确认的选题不生成定稿。

### 发布记录与复盘

用户反馈实际发布的内容后，按内容库模板准备历史笔记；只有收到明确的写入指令后，才将内容写入 `财税视频号内容库/01-历史内容/`，并同步更新内容地图、月度复盘、缺口统计和候选清单。
